# Нулевой модуль магистратуры «Искусственный интеллект»

Репозиторий с заданиями нулевого (адаптационного) модуля программы
«Искусственный интеллект» — НИУ ВШЭ, факультет компьютерных наук,
направление 01.04.02 «Прикладная математика и информатика».

Автор: Артем Панов ([@iamartempn](https://github.com/iamartempn)).

## Домашние задания

### [Homework1](Homework1) — EDA-отчет по датасету

Разведочный анализ набора открытых данных Правительства Москвы № 591
«Перечень субсидий, предоставленных организациям, осуществляющим деятельность
в инновационной и промышленной сферах» (<https://data.mos.ru/opendata/591>):
270 договоров субсидий 2012–2017 годов на общую сумму 11,64 млрд рублей.

| Файл | Что внутри |
|---|---|
| `eda_subsidies.ipynb` | загрузка выгрузки, проверка качества данных, сборка отчета |
| `report.html` | профилирующий отчет, построенный `ydata-profiling` |
| `conclusions.docx` | выводы по датасету и найденным проблемам в данных |
| `data/data-591-2018-04-17.xlsx` | исходная выгрузка с портала, как скачана |
